# 星图镜头连续性修复（2026-10-01）

## 根因与设计

- 导览、回地球、重置和按钮缩放原来直接赋值相机位置；常规模式和减少动态共用了瞬时路径
- 旧跃迁的多个分镜分别修改位置、朝向和视场：120 Hz 采样发现 boost→warp 的视场单帧从 63.926° 跳到 66.064°，另有 liftoff→turn、arrive→settle 的视场重置
- 旧路径共用了可变临时向量，路径中点计算能覆盖终点；跨尺度状态没有被所有新操作取消，返回太阳系的完成回调也会提前丢失
- OrbitControls 的阻尼、重新对准旧目标与动画可能争抢相机；太阳系浮动原点也不应带动银河背景

现使用一个可中断的镜头过渡：捕获当前实际渲染位置、朝向、注视点、视场后统一插值，角度沿最短经向路径过渡，半径取对数插值。采用整段连续的五次缓动，没有独立分镜的视场冲击，也不会穿过世界上轴奇点而突然翻滚。普通输入中的按钮、滚轮、旧目的地、新导览、重置及回家共用此路径；拖动和巡航可从当前帧接管。

太阳系 AU 模型和恒星 ly 模型的半径本来就是不同的可见化夸张比例，不宣称两者之间是物理连续缩放。切换使用真实已渲染源图像与目标实时场景的短交叠；再次切换时先合成当前交叠图像再作为新来源。没有黑幕或空帧。减少动态继续立即导航，并清除正在交叠的图层。

## 回归覆盖

- 真实 CameraController + OrbitControls（仅 DOM 事件面和天文数据源替身），不再通过省略构造函数的对象验证导航
- 同尺度新旧入口、镜头中间帧、连续改目标、废弃回调、连按缩放、滚轮、巡航/观察/拖动接管
- 自动游览抵达前后停止、移动目标跟随、平移保留、浮动原点等价性、横竖屏卫星构图
- 极端背侧视角在中途切换模式，2002 个小步跨原来的上轴翻转区域
- 30/60/120/240 Hz 路径一致性；视场单帧变化不超过整段五次缓动的解析上界；零距离、反向、极大极小半径、无效和恢复标签页 dt
- 新增非“减少动态”的浏览器场景，在同一点击事件读取前后相机以避免跨协议读取漏过单帧瞬移；读取跨尺度源画布像素确认实际图像、验证中断和清理
