# 分子视界与音浪粒子验证

运行：

```sh
node --import tsx --test src/scripts/molecule/*.test.ts src/scripts/audio-viz/*.test.ts
ASTRO_TELEMETRY_DISABLED=1 npm run lint
ASTRO_TELEMETRY_DISABLED=1 npm run build
npm run test:browser -- tests/browser/molecule-audio.spec.ts
```

25 个节点测试覆盖结构快照哈希、分子式、完整价态、键级、氢隐藏计数、DNA 基团与互补配对、手动暂停巡游、音频图隔离、过期异步结果、麦克风延迟授权后释放、暂停/继续/跳转/循环/结束、示例信号边界和真实频率分段。

浏览器规格使用强制 WebGL 不可用情境、减少动态效果和全 mock 的 Web Audio 图，不会请求实际麦克风权限或播放真实声音。检查错误回退、键盘选择原子、模型来源/数量、引导比较、显式启动、声音与画面独立暂停、停止后控件、375px 宽度。

另有正常 WebGL 桌面/移动端截图测试：仅当浏览器未提供标准 WebGL 能力时明确跳过，不添加绕过参数。真实设备音频仍需具备相应能力的环境验证，单元/构建通过不能替代视觉或听觉 QA。环境不支持本地浏览器或 WebGL 时不能借换端口/隧道规避限制。

手动 QA 重点：

1. 分别在普通与减少动态效果模式进入分子页。自动巡游只在普通模式初始开启；手选、点选、比较、换视图和隐藏标签页会暂停。
2. 拖动旋转不应误选；轻点球体应高亮并显示与键盘选择框相同的说明。缩放与三种样式下双键/氢隐藏清楚，重置视角能找回模型。
3. 四种小分子的完整计数为水 3、咖啡因 24、多巴胺 22、5-羟色胺 25。DNA 的 96 是基团节点数，始终不得标为原子数。
4. 音频页加载时没有声音、AudioContext 或权限弹窗。点击示例后才合成 12 秒三频段信号；默认为 20% 回放音量。
5. 文件→麦克风→文件→示例反复切换。分析器始终无扬声器连接；只有文件/示例节点能通过单独 gain 输出。停止或离开页面后麦克风轨道全部停止，晚到的授权也会被释放。
6. 验证单次与循环播放、暂停后跳转、循环多个周期后关闭循环、末尾跳转和重复停止。进度和按钮反映真实音频状态。
7. 画面暂停不暂停声音；音频暂停保留进度；系统减少动态效果只默认冻结画面。百分比是浏览器对数频谱字节值归一化后的 RMS 相对视觉指标，受 minDecibels/maxDecibels 缩放与截断影响，不是线性振幅或专业响度测量。参见 https://www.w3.org/TR/webaudio-1.0/#dom-analysernode-getbytefrequencydata 。
8. bfcache 返回后保持停止，必须再次点击音源。新页面替换时解绑旧事件与取消动画循环。

结构来源与许可边界见 [molecule-sources.md](./molecule-sources.md)。客户端导入四份精简 JSON，`raw/` 原始校验快照不进入运行包。没有新服务、账户、上传或依赖。
