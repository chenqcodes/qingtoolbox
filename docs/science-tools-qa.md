# 科学工具升级与验证边界

## 第一轮：可信的基础

- 今日星空：月相名称使用 Astronomy Engine 的 MoonPhase（0–360°周期），亮面面积使用 phase_fraction；两者不混用。升落、日期输入和显示使用用户明确选择的 IANA 时区。地平线上、最高和最亮是不同判断；白昼不承诺肉眼可见。
- 卫星过顶：TLE 历元从原始第一行读取，与抓取时间分开。检查编号、校验和、数值/物理范围与 SGP4 状态。历元超过7天停算，超过3天提示偏旧。几何过境、暮光与卫星受照条件分别计算；云、山体、建筑、姿态和光污染不在模型内。
- 轨道实验：理想两体、共面圆轨道、瞬时切向点火。正/负 Δv 表示加速/减速，总量为绝对值之和，不是燃料消耗。以开普勒时间方程推进，端点与出发/到达标记一致，等半径无需机动。
- 分子视界：手动选择暂停巡游；示意、简化模型和 DNA 代理节点明确标注。
- 音浪粒子：分析器没有扬声器输出连接；文件播放使用独立支路，切换到麦克风不会继承反馈路径。资源请求被停止或取代后，晚到的媒体流也会释放。
- 轻星图与日照：保留原三维资产和计算架构；WebGL 不可用或丢失时显示恢复提示。日照不在打开页面时自动请求定位权限。

## 第二轮：可探索、可解释

- 轨道提供时间进度拖动、瞬时速度方向箭头、升轨/降轨/等半径预设和只做一次点火的返回实验。每半个轨道压缩为8秒播放；显示相对模型时间，不标作真实秒。箭头长度不代表速度，第二次点火后速度读数明确标作圆化后。
- 其他工具的专项模型、数据来源与交互说明见其对应文档和页面内说明。

## 自动回归

- `npm run test:science`：音频图与竞态、分子巡游、空间能力探测、日照原有算法/降级、月相/时区/TLE/可见窗口
- `npm run check:labs`：所有原有 lab 自检，轨道端点、方向、守恒量、开普勒时间导数
- `npm run test:tools` 和 `npm run test:seo`：保护已上线图片压缩、汉字练习纸及 SEO 行为
- `npm run lint`、`npm run build`、`npm run qa:metadata`、`npm run qa:seo`
- `npm run test:browser`：在 CI Chromium 检查可操作控件、移动端展开明细、无 WebGL 降级、新月/满月和陈旧数据拒绝

本地受限执行环境无法打开 localhost 浏览器，浏览器用例在既有 GitHub Actions 中运行。无 WebGL 降级检查通过不等于三维 GPU 画面已经视觉验收；实际渲染测试须单独记录可用或跳过。任何自动测试都不证明真实天空、化学动力学或住宅法定日照精度。
